# turok2-android-port

Port nativo a Android (ARM64) en C/C++ con Android NDK, CMake y SDL2.

Este repositorio **no contiene ningún dato del juego original**. Debes aportar tus propios archivos desde una copia legítima.

- Compilación: ver [docs/BUILD.md](docs/BUILD.md)
- Formatos de `game.kpf`: ver [docs/FORMATS.md](docs/FORMATS.md)
- Reglas del proyecto: ver [CLAUDE.md](CLAUDE.md)
